Capítulo 01

Como funciona

Ferramentas como o ManyChat fazem uma coisa simples: recebem um aviso da Meta quando alguém interage com o seu perfil e respondem pela API oficial. O ig-auto faz exatamente isso, só que rodando num servidor que é seu.

Pessoa comenta
EBOOK→ Meta avisa o
seu servidor→ ig-auto acha a
automação→ Responde o comentário
e manda a DM

O que ele faz

  • Gatilhos: comentário em post ou reel, comentário na live, mensagem no direct e resposta de story.
  • Palavra-chave: "contém a palavra", "é exatamente a palavra" ou "qualquer mensagem". Acentos e maiúsculas não importam.
  • Fluxos: resposta pública com variações (para não parecer robô), mensagens com botões, cartão com imagem e links, etiquetas e pausas entre mensagens.
  • Painel: você cria e edita tudo pelo navegador, vê uma prévia de como o lead recebe e acompanha o funil: quantos dispararam, quantos seguiram a conversa e quantos clicaram em cada link.
  • Leads: lista com @, etiquetas, automações que a pessoa passou e um botão para abrir o direct dela.

Seja honesto consigo

Em troca de não pagar mensalidade, você assume o servidor. Se ele cair, as respostas param até você subir de novo. Para a maioria dos perfis isso dá pouquíssimo trabalho, mas é bom saber antes.

Capítulo 02

O que você precisa

Separe uma tarde. Com tudo em mãos, a implantação leva de 1 a 3 horas. A maior parte desse tempo vai para o app da Meta.

Lista de compras

ItemPara quêObservação
Servidor (VPS)Onde o ig-auto roda 24 horasO plano mais simples já basta (1 vCPU, 1 GB de RAM), com Ubuntu 22.04 ou 24.04
DomínioA Meta só conversa com endereços https://Pode ser um subdomínio de um site que você já tem, como auto.seusite.com
Instagram profissionalA conta que vai responderComercial ou criador de conteúdo. Conta pessoal não funciona.
Conta de desenvolvedor MetaCriar o app que conversa com o InstagramGratuita, em developers.facebook.com
Um segundo perfil do InstagramTestar como se fosse um clienteA automação não responde à própria conta

Termos que vão aparecer

  • VPS: um computador alugado na internet, ligado o tempo todo.
  • SSH: o jeito de "entrar" no servidor pelo terminal para digitar comandos.
  • Webhook: o aviso que a Meta manda para o seu servidor quando algo acontece no perfil.
  • Token: a autorização que o Instagram dá ao seu app para responder em nome da conta. Vale 60 dias, e o ig-auto renova sozinho. Só que, se você trocar a senha do Instagram, a Meta derruba o token, e aí é preciso entrar de novo no painel.
  • .env: o arquivo com as senhas e configurações do seu ig-auto. Nunca compartilhe nem publique esse arquivo.
Dica

Anote num bloco de notas, à medida que avança: o domínio, o ID e a chave secreta do app, o token de verificação e a senha de admin. Você vai usar cada um mais de uma vez.

Capítulo 03

Preparar o servidor

Neste capítulo você liga o servidor, aponta o domínio para ele, ativa o HTTPS e deixa o ig-auto rodando. Os comandos são para Ubuntu.

  1. Aponte o domínio. No painel onde você comprou o domínio, crie um registro A apontando (por exemplo) auto.seusite.com para o IP da sua VPS. Pode levar alguns minutos para valer.
  2. Entre no servidor e instale o básico: 
    # no seu computador
ssh root@IP_DA_VPS

# já dentro do servidor: Node 22, nginx, certificado HTTPS e git
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs nginx certbot python3-certbot-nginx git
npm install -g pm2
  3. Baixe o ig-auto e crie o seu .env: 
    cd /opt
git clone https://github.com/SEU_USUARIO/ig-auto.git
cd ig-auto
npm install
cp .env.example .env
nano .env
    Por enquanto, preencha só o que já dá para preencher: 
    PUBLIC_URL=https://auto.seusite.com
VERIFY_TOKEN=invente uma palavra longa, ex.: banana-azul-7731
ADMIN_KEY=gere com: openssl rand -hex 16
SESSION_SECRET=gere com: openssl rand -hex 32
PANEL_USERS=seu @ do Instagram, sem o @
    Para salvar no nano: Ctrl+O, Enter, Ctrl+X.
  4. Ligue o nginx para o seu domínio. Crie o arquivo /etc/nginx/sites-available/ig-auto: 
    server {
    server_name auto.seusite.com;
    location / {
        proxy_pass http://127.0.0.1:3020;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
    ln -s /etc/nginx/sites-available/ig-auto /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot --nginx -d auto.seusite.com   # ativa o HTTPS
  5. Suba o ig-auto e deixe ele ligado para sempre: 
    cd /opt/ig-auto
pm2 start npm --name ig-auto -- start
pm2 save && pm2 startup   # volta sozinho se o servidor reiniciar
    Abra https://auto.seusite.com/health no navegador. Se aparecer {"ok":true,...}, o servidor está pronto.
Num subcaminho

Se o ig-auto vai ficar em seusite.com/ig-auto em vez de um subdomínio, use location /ig-auto/ { proxy_pass http://127.0.0.1:3020/; ... } e coloque PUBLIC_URL=https://seusite.com/ig-auto.

Capítulo 04

Criar o app na Meta

O app é a "identidade" do seu ig-auto perante a Meta. É a parte com mais telas, e a Meta muda os nomes dos menus de tempos em tempos. Se algo estiver com outro nome, procure pela palavra-chave em negrito.

  1. Crie o app. Em developers.facebook.com → Meus apps → Criar app, escolha o caso de uso "Gerenciar mensagens e conteúdo no Instagram" e, se for perguntado, a API com login do Instagram.
  2. Pegue as credenciais. Em Configuração da API com login do Instagram, copie o ID do app do Instagram e a chave secreta do app do Instagram. Coloque no .env como IG_APP_ID e IG_APP_SECRET e rode pm2 restart ig-auto.
  3. Configure o webhook. Na seção de webhooks:
    • URL de callback: https://auto.seusite.com/webhook
    • Token de verificação: o mesmo VERIFY_TOKEN do .env
    • Clique em verificar e salvar. Depois assine os campos comments, live_comments, messages, messaging_postbacks, messaging_seen e message_reactions.
  4. Cadastre o retorno do login. Em Login comercial do Instagram, adicione a URI de redirecionamento https://auto.seusite.com/oauth/callback.
  5. Publique uma política de privacidade. O repositório traz um modelo em privacidade/index.html. Troque os campos entre colchetes, publique no seu site e cole a URL nas configurações básicas do app. Troque também os campos de Termos e Exclusão de dados, que vêm preenchidos com facebook.com.
  6. Torne-se testador. Em Funções → Testadores do Instagram, adicione o seu perfil. Depois, no Instagram, aceite o convite em Configurações → Apps e sites.
  7. Publique o app. Mude o app para o modo publicado (Live). Sem isso, o webhook não entrega nada.
Preciso de revisão da Meta?

Para automatizar o seu próprio perfil, não. Com o app publicado no acesso padrão, as contas que têm função no app (você, como testador) conectam normalmente, e comentários e DMs de qualquer pessoa chegam ao webhook. A revisão (acesso avançado) só é necessária se você quiser que outros perfis conectem no seu app, como num serviço para clientes.

Pegadinha conhecida

Se ao convidar o testador pela aba Funções aparecer "O formulário não pode ser salvo", vá no passo de gerar tokens da configuração da API, clique em "Adicionar conta" e escolha o perfil na lista de sugestões.

Capítulo 05

Conectar e testar

Agora o seu servidor e o app se conhecem. Falta autorizar o perfil e fazer o teste de fumaça: o primeiro "oi" automático.

  1. Conecte o perfil. Abra no navegador: 
    https://auto.seusite.com/connect?key=SEU_ADMIN_KEY
    Entre com o Instagram e autorize. Deve aparecer "✅ @seuperfil conectado". Nesse momento o ig-auto guarda o token e assina os webhooks da conta.
  2. Ligue o modo teste. No .env, deixe SMOKE_TEST=1 e rode pm2 restart ig-auto.
  3. Comente "teste" num post seu usando o segundo perfil. Em poucos segundos devem chegar uma resposta pública ("Te chamei no direct 👀") e uma DM.
  4. Acompanhe ao vivo, se quiser ver o que está acontecendo: 
    pm2 logs ig-auto
  5. Feche o modo teste e ligue a segurança. Com tudo funcionando, ajuste o .env e reinicie: 
    SMOKE_TEST=0
SIGNATURE_ENFORCE=1   # só aceita avisos assinados pela Meta
Funcionou?

Então a parte difícil acabou. Daqui pra frente é criatividade: tudo o mais acontece no painel, sem comando nenhum.

Se não chegou nada

Vá direto ao capítulo 08. Em 9 de cada 10 casos, o problema é um destes: app não publicado, comentário feito pela própria conta ou o campo comments não assinado no webhook.

Capítulo 06

Sua primeira automação

Acesse https://auto.seusite.com/painel/ e clique em Entrar com Instagram. Só os @ listados em PANEL_USERS conseguem entrar.

Montando o fluxo

  1. Onde dispara: marque comentário em post ou reel, live, direct ou resposta de story. Pode marcar vários.
  2. Em qual post: qualquer um ou um post específico, escolhido pela miniatura.
  3. Palavras-chave: por exemplo, ebook. Use palavras curtas, fáceis de digitar e que ninguém escreveria sem querer.
  4. Respostas públicas: escreva 3 ou mais variações. O ig-auto sorteia uma por vez para não parecer robô.
  5. Mensagens: monte a sequência com mensagens, botões, cartão com link e etiquetas. Use "Reproduzir a conversa" para ver no celular de prévia exatamente o que o lead vai receber.
  6. Salve e ligue. Pronto, já está valendo.

As regras da Meta (que o motor já respeita)

A regra mais importante

A partir de um comentário, a Meta deixa você mandar uma única DM até a pessoa responder. Por isso a primeira mensagem precisa de um botão ("Quero receber 👉"). Quando a pessoa clica, a conversa fica aberta e o resto do fluxo pode seguir. O painel avisa se você esquecer.

  • Limites de formato: até 3 botões por mensagem, 20 caracteres por botão, 80 no título do cartão e 1000 por mensagem. Os links precisam começar com https://.
  • Sem spam: a mesma pessoa não recebe o mesmo fluxo duas vezes em 12 horas. Se ela comentar de novo, recebe só a resposta pública.
  • Janela de 24 horas: no direct, a Meta só deixa você responder dentro de 24 horas depois da última mensagem da pessoa.
  • Plano B automático: se a Meta recusar um formato (cartão ou botões), o envio tenta respostas rápidas e, por último, texto com o link.

Acompanhando os resultados

Na lista de automações, cada uma mostra o seu funil: disparos → seguiram a conversa → cliques em cada link. Os links passam por um endereço do próprio ig-auto (/r/código), e é assim que ele sabe quem clicou. Na aba Leads você filtra por etiqueta e abre o direct de cada pessoa com um clique.

Capítulo 07

Ideias que vendem

Uma automação boa entrega exatamente o que foi prometido no vídeo, rápido, e faz uma pergunta ou dá um próximo passo. Oito modelos para adaptar:

Material gratuitoEBOOK

"Comenta EBOOK que eu te mando." Botão de confirmação → cartão com o link de download → etiqueta ebook. É o exemplo que já vem no repositório.

Lista de esperaQUERO

Para lançamentos: DM explica a data e o botão leva ao formulário ou ao grupo. Etiqueta lista-espera para chamar no dia da abertura.

CupomCUPOM

Reel do produto → DM com o código e o link da loja já com o desconto. Use um código diferente por vídeo para saber qual vendeu mais.

Diagnóstico ou orçamentoDIAGNÓSTICO

Serviços: duas ou três mensagens mostrando a dor e o método, depois um cartão com dois caminhos: "Fazer o diagnóstico" (página) ou "Falar no WhatsApp" (link wa.me com o texto pronto).

LiveLINK

Durante a live, quem comenta a palavra recebe o link da oferta na hora, sem você parar para responder.

Resposta de storyqualquer palavra

Story com caixa de pergunta ou "responde SIM": dispare com "qualquer mensagem" num story específico e abra com "Que bom que você respondeu meu story!".

Direct de boas-vindasPREÇO

As perguntas que mais chegam no direct ("preço", "valor", "como funciona") com resposta pronta e um botão para falar com uma pessoa.

AgendaAGENDA

Para clínicas e consultórios: link direto para o agendamento online, com etiqueta para a equipe confirmar depois.

Teste rápido

Coloque UTMs nos links (?utm_source=instagram&utm_medium=dm&utm_campaign=ebook) para ver no seu site ou CRM quantas vendas vieram de cada palavra.

Capítulo 08

Quando algo dá errado

O primeiro lugar a olhar é sempre o log: pm2 logs ig-auto. Cada evento recebido aparece ali com a origem e o texto.

SintomaCausa provávelSolução
Nada aparece no log ao comentarApp não publicado ou campo não assinadoPublique o app (modo Live) e confira os campos assinados do webhook
O webhook não verifica na MetaToken diferente, ou servidor fora do ar ou sem HTTPSConfira o VERIFY_TOKEN, o /health e o certificado
Comentei e não respondeuComentou com a própria contaTeste com outro perfil. A conta nunca responde a si mesma.
Respondeu só no comentário, sem DMA mesma pessoa já recebeu esse fluxo há menos de 12 horasÉ proposital (antispam). Teste com outro perfil ou espere.
webhook_bad_signature no logIG_APP_SECRET erradoCopie de novo a chave secreta do Instagram, não a do app Facebook
"não tem acesso a este painel"@ fora do PANEL_USERSAdicione o @ (sem o @) e reinicie
Parou de responder de uma hora para outra (erro 190 ou "session has been invalidated" no log)A Meta derrubou o token, normalmente porque a senha do Instagram foi trocada, ou o token venceu com o servidor desligadoEntre de novo no painel com Entrar com Instagram (ou abra /connect?key=…). Isso salva um token novo e reassina os webhooks.
Botão não aparece, só textoA Meta recusou o formatoNormal: o plano B entregou em texto. Confira o tamanho dos títulos.
O erro mais traiçoeiro: token caído

Quando o token cai, nada quebra visivelmente: o servidor continua no ar, o /health responde ok e os comentários chegam ao log, mas nenhuma resposta sai. Dá para passar dias sem perceber. Sempre que trocar a senha do Instagram, entre de novo no painel. E, de vez em quando, comente a palavra de uma automação com um segundo perfil para confirmar que está tudo respondendo.

Depois que você reconecta, quem tentou durante a queda pode tentar de novo na hora: tentativas que falharam antes de enviar qualquer DM não contam na pausa de 12 horas.

Atualizando o ig-auto

cd /opt/ig-auto
git pull
npm install
pm2 restart ig-auto

Suas automações e leads ficam na pasta data/ e não são afetados pela atualização.

Backup

Tudo o que importa está em data/ig-auto.db e no .env. Copie os dois de tempos em tempos para um lugar seguro, e nunca para um repositório público: eles têm os tokens da sua conta e os dados dos seus leads.

Capítulo 09

Checklist final

Antes de falar a palavra-chave num vídeo, confira:

Servidor

  • https://seudominio/health responde ok
  • O pm2 startup foi executado (o ig-auto volta sozinho se o servidor reiniciar)
  • SMOKE_TEST=0 e SIGNATURE_ENFORCE=1
  • Backup do .env e de data/ guardado
  • Combinado com a equipe: trocou a senha do Instagram, entra de novo no painel

Meta

  • App publicado (Live)
  • Webhook verificado, com os 6 campos assinados
  • Política de privacidade com os seus dados, publicada
  • Perfil conectado pelo /connect

Automação

  • Palavra-chave curta, fácil e falada no vídeo exatamente como está no painel
  • A primeira DM depois de um comentário tem botão
  • Todos os links abrem, começam com https:// e têm UTM
  • Testado com um segundo perfil, do comentário até o clique no link
  • Automação ligada no painel
Responsabilidade com os dados

Os dados dos seus leads ficam no seu servidor, e você é o responsável por eles perante a LGPD. Responda a pedidos de exclusão, não compartilhe a base e mantenha a política de privacidade atualizada.
